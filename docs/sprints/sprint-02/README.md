# Sprint 02 — Backend streaming and web player

## Goal

Make the backend a usable browser-based music player.

## Deliverables

- Authenticated HTTP byte-range streaming.
- Browse, search, album, artist, and track pages.
- Persistent web audio player and queue.
- Playback sessions and browser Media Session controls.
- Manual playlists and playlist editor.
- Production-compatible internal reverse-proxy audio delivery.

## Exit criteria

- Large MP3 files seek and resume correctly.
- Navigation and refresh preserve the current queue.
- Unauthorized users cannot obtain audio by guessing URLs.
- Streaming works with each storage backend.
