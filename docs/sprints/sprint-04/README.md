# Sprint 04 — Activities, geofences, and contextual sessions

## Goal

Let the user describe where and why music is playing.

## Deliverables

- Cycling, running, gym, focus, walking, relax, commute, and custom activities.
- Named geofence CRUD and privacy controls.
- Manual place selection in the web player.
- Immutable context snapshots and workout phases.
- Setup UI for activity, place, duration, energy, and discovery.
- Context-filtered listening history and forget-learning behavior.

## Exit criteria

- Sessions and events carry immutable context snapshots.
- Playback events reference geofence IDs instead of raw coordinates by default.
- Location denial/manual use remains fully functional.
- Place deletion and forgetting learned associations are tested.
