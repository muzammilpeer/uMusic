# uMusic sprint workspace

Work through these folders in order. Each sprint contains:

- `README.md`: goal, scope, deliverables, exit criteria, and dependencies.
- `PROMPT.md`: a self-contained prompt for starting that sprint.

Do not start the next sprint until the current sprint's exit criteria and the
project-wide [definition of done](../08-definition-of-done.md) are satisfied.
