# Sprint 13 — Field learning and release quality

## Goal

Prove that the complete system is reliable and its recommendations improve.

## Deliverables

- Multi-week evaluation dashboard/report by activity and model version.
- Playback, crash, battery, cache, sync, and recommendation improvements.
- Data export, deletion, and forget controls.
- Security review, threat-model update, runbook, and release checklist.
- Complete backup/restore and server-to-offline-workout exercises.

## Exit criteria

- No critical data-loss, playback, privacy, or authentication defects remain.
- Recommendation metrics improve or a documented deterministic fallback is used.
- Backup/restore succeeds.
- The full server-to-airplane-mode-workout journey is repeatable.
