# Sprint 10 — SwiftUI foundation and online playback

## Goal

Browse and play the uMusic backend from an iPhone, including locked-screen audio.

## Deliverables

- SwiftUI application with testable networking, storage, and audio boundaries.
- Secure onboarding and Keychain device token.
- Library, search, playlist, queue, and Now Playing screens.
- Background audio and Lock Screen/Control Center/headphone commands.
- Online listening-event capture and synchronization.

## Exit criteria

- Playback continues while the screen is locked.
- Remote commands and queue persistence work consistently.
- Events reach the backend idempotently.
- Revoking the device in the web portal blocks future access.
