# Sprint 12 — Workout and place intelligence

## Goal

Apply activity and location context safely during real workouts and focus sessions.

## Deliverables

- Cycling, running, gym, walking, focus, relax, and custom session UI.
- Optional Core Location geofence resolution.
- Optional HealthKit workout integration.
- Workout phases and bounded reranking of future tracks.
- Minimal glanceable player and battery/privacy diagnostics.

## Exit criteria

- A physical cycling/running test completes with locked-screen audio.
- Prepared playback needs no network.
- Location denial leaves manual context functional.
- Raw route storage remains opt-in.
- Context changes never interrupt the current track.
