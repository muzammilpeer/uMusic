# Sprint 08 — Scheduled intelligence and web polish

## Goal

Make the backend/web product dependable for daily use.

## Deliverables

- Scheduled and manual smart-playlist refresh.
- Missing/wanted-track inbox.
- Storage, worker, import, playback, and recommendation dashboards.
- Responsive and accessible web UI.
- Backup/restore commands and isolated restore exercise.
- Performance tests for a generated 50,000-track catalog.

## Exit criteria

- Daily operation does not require Django admin.
- Scheduled jobs are observable, retryable, and idempotent.
- Backup restore reconstructs database/media references.
- Important catalog queries meet documented targets.
