# Sprint 05 — Learning engine version 1

## Goal

Convert listening events into explainable global and contextual preferences.

## Deliverables

- Versioned signal weights and aggregation jobs.
- Track, artist, genre, activity, place, and time affinities.
- Confidence, evidence thresholds, and implicit-signal time decay.
- Explicit preference overrides.
- Deterministic rebuild/reset controls and learning dashboard.

## Exit criteria

- A complete rebuild from events is deterministic.
- Explicit dislikes override implicit positive signals.
- A single ambiguous skip cannot create a strong affinity.
- Every affinity exposes supporting evidence and algorithm version.
