# Beta Help and Feedback

- **No music appears:** confirm the private server connection, then use the explicit Sync action. uMusic does not sync the library automatically at launch.
- **Playback cannot start:** check whether the track is available, retry the connection, or download it for offline playback. Expired media tickets are refreshed without discarding the queue.
- **Downloads do not start:** review Wi-Fi/cellular, charging, free-space, and quota status. Pinned media is not automatically evicted.
- **Activity is unknown:** choose an activity manually. Motion, HealthKit, and location remain optional and unsupported controls are hidden on macOS.
- **Restored song is paused:** this is intentional; uMusic never autoplays after relaunch.
- **Report a beta problem:** include app build, device/OS, cached-versus-streamed, and reproduction steps. If you opted into Beta Diagnostics, export its aggregate report. Never send credentials, server tokens, full URLs, location, HealthKit records, or listening-history exports in a feedback ticket.
