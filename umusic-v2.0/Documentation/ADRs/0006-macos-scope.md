# ADR 0006: macOS Scope

- Status: Provisional
- Date: 2026-08-09

## Decision

Plan a full macOS library, playback, playlist, offline, settings, export, and inspector experience. Exclude HealthKit and Core Motion classification; retain manual activity and supported Core Location/network/power adapters.

## Consequences

Shared domain behavior stays platform-neutral while UI and context adapters use explicit capabilities. Product owner must confirm this scope before Sprint 1 target creation.
